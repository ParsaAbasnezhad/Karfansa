# Iran province map data

`iran-provinces-map.json` contains simplified province boundary paths derived
from [Iran-geojson-map-boundaries](https://github.com/ssepehrnoush/Iran-geojson-map-boundaries),
which identifies its source as OpenStreetMap administrative boundary data.
The source boundary data and this derived boundary dataset are available under
the [Open Database License 1.0 (ODbL)](https://opendatacommons.org/licenses/odbl/1.0/).

The map UI attributes the data to
[© OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
The ODbL applies to the boundary data, not to the application code or the
rendered map as a produced work.
