# ۰۰۰۴: ارائه‌دهنده‌های LLM و جست‌وجوی وب

**وضعیت:** تصمیم گرفته شده، هنوز پیاده نشده

## تصمیم
- رابط‌های `LLMProvider` (پیاده‌سازی‌ها: `OpenAICompatibleProvider`، `AnthropicProvider`) و
  `WebSearchProvider` (RSS، API جست‌وجو، SearXNG) قابل‌تعویض با تنظیمات.
- ارکستراتور جمع‌آوری **کدمحور و مرحله‌ای** است. LLM فقط گسترش عبارت، استخراج و دسته‌بندی با
  خروجی Pydantic انجام می‌دهد؛ بدون ابزار و بدون دسترسی به دیتابیس.
- تطبیق نقل‌قول با متن منبع با کد انجام می‌شود. رکورد وب خودکار «شرکت تأییدشده» نمی‌شود.
- جمع‌آوری در Celery اجرا می‌شود و خطای ارائه‌دهنده جست‌وجوی داخلی را مختل نمی‌کند.
- Ollama اختیاری است (profile جدا در Compose)، و پیش‌فرض `LLM_PROVIDER=none`.
- پیش از پیاده‌سازی گسترده، یک اسپایک با مجموعه‌داده‌ی برچسب‌خورده کیفیت را می‌سنجد.
