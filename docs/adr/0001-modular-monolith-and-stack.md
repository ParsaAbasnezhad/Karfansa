# ۰۰۰۱: Modular Monolith و فناوری‌ها

**وضعیت:** پیاده‌شده (اسکلت)

## تصمیم
- یک برنامه‌ی Django (Modular Monolith) با لایه‌ی API در Django Ninja، و یک برنامه‌ی جدای React (Vite + TypeScript).
- PostgreSQL برای داده، Redis برای کش و صف، Celery برای کارهای پس‌زمینه.
- Docker Compose برای توسعه. API با پیشوند نسخه‌دار `/api/v1/`.
- هر اپ جنگو فقط وقتی ساخته می‌شود که لازم شود. اپ‌ها فقط از طریق `services` با هم حرف می‌زنند.
- Python 3.12 و Django 5.2 LTS، مدیریت وابستگی با `uv` و `npm`.

## دلیل
سادگی عملیاتی برای تیم کوچک، با مرزهای ماژولی که بعداً در صورت نیاز قابل جدا شدن باشند.
Microservices و ابزارهای پیچیده تا وجود نیاز فنی مشخص اضافه نمی‌شوند.

## پیامد
فاز ۱ فقط اپ `core` (سلامت سرویس، قالب خطا، تسک نمونه) را دارد.
