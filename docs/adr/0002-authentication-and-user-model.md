# ۰۰۰۲: احراز هویت و مدل کاربر

**وضعیت:** تصمیم گرفته شده، هنوز پیاده نشده

## تصمیم
- نشست‌های Django با کوکی `HttpOnly`، `SameSite=Lax` و محافظت CSRF، نه توکن در `localStorage`.
- فرانت و API هم‌مبدأ هستند (در توسعه با پروکسی Vite، در تولید با reverse proxy)، پس CORS لازم نیست.
- هش رمز: Argon2 (با PBKDF2 برای سازگاری). محدودسازی نرخ روی ورود و عملیات حساس.
- مدل کاربر سفارشی (ورود با ایمیل) **اولین مایگریشن پروژه** است.

## چرا هنوز نیست
Django بعد از اولین `migrate` تغییر `AUTH_USER_MODEL` را به‌سختی تحمل می‌کند. برای همین قالب فعلی
عمداً `auth`، `admin` و `sessions` را نصب نکرده است. وقتی نوبت احراز هویت رسید، اپ `accounts` با
مدل کاربر سفارشی را اول از همه اضافه می‌کنیم و بعد این سه را فعال می‌کنیم.
